1. Estructura del Documento base

<!DOCTYPE html>

Declara la versión del documento HTML al navegador.

<html>

Elemento raíz. Atributos: lang, dir.

<head>

Metadatos del documento. No visible directamente.

<title>

Título de la pestaña del navegador.

<meta>

charset, viewport, description, author, robots, og:*.

<link>

Hoja de estilos externa, iconos, preconnect, preload.

<style>

CSS incrustado en el documento HTML.

<script>

JS embebido o externo (src). async, defer, type=module.

<base>

URL base para todos los enlaces relativos.

<noscript>

Alternativa si JavaScript está deshabilitado.

<template>

Fragmento HTML inerte que JS puede clonar e insertar.

<body>

Contenido visible de la página.

    8. Elementos Interactivos interactive

    details · summary

    ¿Qué es el modelo de caja en CSS?
    Todo elemento es una caja rectangular: contenido + padding + border + margin. Con box-sizing: border-box, el padding y border se incluyen dentro del width declarado.
    ¿Cuándo usar <section> vs <div>?
    <section> implica una sección temática con encabezado propio, visible en el esquema del documento. <div> no tiene significado semántico y sirve solo para agrupación o aplicación de estilos.

    Multi-columna

    column-count · column-gap · column-rule · column-span

    Título que ocupa todas las columnas (column-span: all)

    Las columnas CSS permiten distribuir texto de forma fluida en múltiples columnas, como un periódico o revista. Se controla con column-count, column-width y column-gap.

    La propiedad column-rule dibuja una línea divisoria entre columnas, similar a un borde pero sin ocupar espacio. Muy útil para contenidos largos como artículos o documentación.
